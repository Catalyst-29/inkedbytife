# Inked by Tife

Premium Fine-Line & Micro-Realism Tattoo Studio landing page for **Inked by Tife** based in Ibadan, Nigeria.

## Features

- **Modern Editorial Aesthetic**: Luxury off-white/cream branding with dark text accents.
- **Custom Showcase Gallery**: Responsive, filterable portfolio grid displaying recent client works (Fine-Line, Micro-Realism, and Geometric).
- **Interactive Multi-Step Booking**: Structured consultation form designed to capture client conceptual requests, sizing, placement, and time slots.
- **Client Testimonials**: Dynamic carousel highlighting reviews and healed work progress.
- **Fully Responsive**: Tailored layouts for mobile, tablet, and desktop devices.

## Tech Stack

- HTML5 (Semantic Structure)
- Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid, Transitions)
- JavaScript (DOM, Interaction & Validation Logic)
